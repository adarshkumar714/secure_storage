Storage Highlights

How CloudLock protects your storage

01

Encrypted Before Upload

Files are encrypted in the browser before reaching the server, so storage keeps unreadable encrypted content.

02

User-Controlled Vault Key

The user controls the vault key for upload, preview, and download, which helps keep access limited to the intended person.

03

Organized Secure Storage

Encrypted files are stored in the uploads folder while user and file records are managed safely in the project database.

How It Works

Simple secure folder flow

01 Create a folder

Users create a secure folder with a unique folder name and private vault key.

02 Upload into that folder

Files are encrypted in the browser and stored under the selected secure folder.

03 Unlock folder later

Users must enter the correct folder vault key before any files inside become visible.

04 View or download safely

Only after unlocking can users preview, download, or delete the files in that folder.
